# Nurettin Sakoğlu — Gayrimenkul Danışmanlığı

Statik GitHub Pages sitesi. Ana sayfa ve müşteri yorumları arşivi Türkçe, İngilizce, Almanca ve Arapça arayüz desteğine sahiptir.

## İçerik

- Güncel çalışma: ASVONEX
- Geçmiş deneyim: RE/MAX Kuzey
- 2021–2026 döneminden 304 müşteri yorumu
- Arama ve yıl filtresi bulunan yorum arşivi
- Arama motoru meta verileri, yapılandırılmış veri, `robots.txt` ve `sitemap.xml`

## Fotoğraf güncellemesi

Güncel portre hazır olduğunda ana sayfadaki `.profile-visual` alanına optimize edilmiş WebP/AVIF görsel eklenebilir. Görsel dosyası yerel olarak barındırılmalı; harici bir kurumsal sunucuya bağımlı bırakılmamalıdır.
